##### chatagne 自定义模块

用于控制 OSCVideoPlayer

支持组播/单播

     组播地址默认`239.0.0.139:8000`, 组播地址运行时可切换, 组播端口暂时不支持切换
    
     本机监听端口:`12000`, 运行时可切换 

支持多节点自动同步播放 

程序启动会默认加入组播组, 如果不希望节点加入, 在 `Multicasr Members` 容器中选 `Leave` 使它离开

当前版本未考虑单控, 如果要单控各节点, 需要使它离开组播组、新建模块、修改组播地址和监听端口、在 `Multicasr Members` 中选 `Join` 使它加入新组播组

所有命令均有提示
